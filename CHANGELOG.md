# Changelog

All notable changes to OpenKrishi AI are documented here.

The format follows Keep a Changelog and releases use Semantic Versioning.

## [Unreleased]

### Added

- Fresh-clone development commands and dependency lockfiles.
- Backend and frontend quality tooling.
- Docker and development-container configuration.
- Expanded onboarding and architecture documentation.
- PWA API and language modules with unit tests.

### Changed

- Backend runtime dependencies are pinned.
- Active deployment configuration no longer requires Gemini or legacy provider settings.
- PWA advisory requests use the shared API client.

### Security

- Secret scanning and CodeQL workflows remain enabled.
- Upload limits and rate limiting protect the public API boundary.

## [0.1.0]

Initial public development milestone.

### Added

- Multilingual agricultural advisory foundation.
- Crop image assessment.
- Voice transcription and advisory pipeline.
- Weather integration.
- Firebase security rules.
- Render deployment configuration.
- Safety and threat-model documentation.
