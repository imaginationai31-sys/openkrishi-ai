# OpenKrishi AI — Google Play release plan

Display name: OpenKrishi AI
Proposed Android application ID: ai.openkrishi.app
Category: Agriculture

Release pipeline:
GitHub tests -> production build -> Firebase App Distribution -> Google Play internal testing -> closed testing -> production.

Required before production:
- signed Android App Bundle
- Play App Signing
- privacy policy URL
- Data Safety declaration
- content rating
- store listing assets
- camera/microphone permission justification
- App Check + Play Integrity
- Crashlytics
- account deletion and privacy flows
- final privacy/data-retention review

This is a planning baseline, not a declaration that the app is currently Play Store compliant.
