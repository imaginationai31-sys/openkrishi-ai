# Security Policy

## Reporting a vulnerability

Please do not publicly disclose security vulnerabilities before the maintainers have had an opportunity to investigate them.

Report security issues through the private security reporting mechanism available in the GitHub repository. If that mechanism is unavailable, contact the project maintainer privately through the contact information published in the repository profile.

## Agricultural safety

If you discover an unsafe agricultural recommendation, hallucinated claim, dangerous treatment instruction, or other issue that could cause harm, please report it as soon as possible and include a reproducible example when safe to do so.

Do not include private farmer information in reports.
